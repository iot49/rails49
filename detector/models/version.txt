unreleased

No detector model has ever been published, and the tracer's must not be.

`classifier/resnet/models/version.txt` carries a real version because that model
ships: bumping it, cutting a GitHub Release and uploading the assets is what
publishing means there. Nothing equivalent has happened here, so a version
number would be a claim rather than a record.

The tracer model is trained on 46 fixture images below `layout.min_dpt` with a
six-image validation split. It exists to prove the pipeline runs end to end, and
no number derived from it estimates how a real model would behave. Publishing it
would put a model in front of users that nothing has measured — see `SPEC.md`
§ Accuracy, which also explains why there is no automated model gate to catch
that for you.

The first real version waits on the fresh higher-DPT corpus and a held-out
protocol. Give it `v0.1.0` then, not before.
